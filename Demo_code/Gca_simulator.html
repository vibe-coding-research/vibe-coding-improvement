GCA 서명 시뮬레이터

AI가 코드를 만드는 순간, 어떤 모델이 어떤 요청으로 언제 만들었는지를 서명과 함께 기록합니다. 오른쪽에 예시 코드의 증명서가 이미 나와 있습니다. 코드를 바꿔 서명 만들기를 다시 누르거나, 아래 실험 네 가지를 차례로 해 보세요.

1

AI가 만든 코드를 넣으세요

예시를 고르거나 직접 붙여 넣어도 됩니다.

2

서명을 만드세요

브라우저가 실제 SHA-256 · HMAC-SHA256을 계산합니다.

3

코드 출생 증명서

이 코드가 어디서 왔고 믿을 수 있는지 보여 줍니다.

왼쪽에서 서명 만들기를 누르면 여기에 증명서가 나옵니다.

해 볼 실험

버튼을 누르면 코드를 바꾸고 서명을 다시 만들어, 무엇이 달라지는지 바로 보여 줍니다.

  1. 주석만 바꾸기

    설명(주석)만 고친 코드는 같은 코드로 알아봐야 합니다.

  2. 로직 바꾸기

    동작이 바뀐 코드는 다른 블록으로 기록돼야 합니다.

  3. 기록을 몰래 고치기

    누군가 증명서의 모델 이름을 바꿔 치면 서명이 맞지 않습니다.

  4. 검토자 넣기

    사람이 검토한 기록이 붙으면 등급이 올라갑니다.
